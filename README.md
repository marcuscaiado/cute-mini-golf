# ⛳ Cute Mini Golf 3D

[![Live Demo](https://img.shields.io/badge/🎮_Play_Live_Demo-marcuscaiado.github.io-success?style=for-the-badge&logo=githubpages&logoColor=white)](https://marcuscaiado.github.io/cute-mini-golf/)

[![Three.js](https://img.shields.io/badge/Three.js-000000?style=flat&logo=three.js&logoColor=white)](https://threejs.org/)

A cute, colorful 3D mini-golf game with Nintendo-inspired visuals built with **Three.js**, **Cannon-es** physics, and procedural **Web Audio API** sound effects.

## ✨ Features

- 🐰🐸🐥 **3 Playable Characters** — Bunny, Froggy, and Chicky, each with unique 3D models
- 🏌️ **Click & Drag Controls** — Intuitive pull-back aiming and power meter
- 🔊 **Procedural Web Audio SFX** — Dynamic sounds for club swings, wall bounces, hole sinks, and victory fanfares
- 🌳 **Vibrant 3D Aesthetics** — Low-poly trees, flowers, floating clouds, shimmering pond, and animated flag
- 🎯 **3D Physics Simulation** — Powered by Cannon-es with rolling friction and soft wall bounces
- ⛳ **Score & Celebrations** — Hole in One, Eagle, Birdie, and Par popups with victory animations
- 🔄 **Play Again** button for quick restarts
- 📱 **Cross-Platform** — Full touch controls on mobile & tablet

## 🚀 Local Development

```bash
npm install
npm run dev
```

Then open `http://localhost:5173` in your browser.

## 🛠️ Tech Stack

- **Vite** — High-performance frontend toolchain
- **Three.js** — 3D graphics and camera controls
- **Cannon-es** — 3D rigid-body physics engine
- **Web Audio API** — Synthesized, zero-asset audio effects
