## ✨ Features & Highlights

- 🐰🐸🐥 **3 Playable Kawaii Characters** — Bunny, Froggy, and Chicky, each with unique animated 3D models and putters.
- 🏌️ **Click & Drag Aiming** — Intuitive pull-back power slingshot aiming and trajectory line.
- 🎯 **3D Physics & Cup Suction** — Cannon-es physics engine with rolling ball friction, soft bumper bounces, and authentic cup rim gravitational suction.
- 🌳 **Vibrant Nintendo Aesthetic** — Low-poly trees, animated flowers, floating clouds, shimmering water hazards, and fluttering flags.
- 🔊 **Procedural Web Audio SFX** — Dynamic sounds for club swings, wall bounces, cup sinks, and victory fanfares.
- 🏆 **Global Leaderboard Sync** — Real cloud high-score records synced with the Marcus Arcade Hub via GitHub Gist API.
- 📱 **100% Cross-Platform** — Full responsive touch controls on mobile & tablet.

## 🕹️ Controls

| Action | Desktop / Mouse | Mobile / Touch |
| :--- | :--- | :--- |
| **Aim & Set Power** | Click and pull back on ball | Touch and drag backward |
| **Release Stroke** | Release Left Mouse Button | Release Finger |
| **Switch Golfer** | Click Character Avatar | Tap Character Avatar |

---

## 🛠️ Tech Stack

- **Three.js** — 3D graphics rendering, lights, and camera controls
- **Cannon-es** — 3D rigid-body physics simulation
- **Web Audio API** — Synthesized, zero-asset audio effects
- **Vite** — Fast frontend build toolchain
