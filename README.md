# ⛳ Cute Mini Golf 3D

A cute, colorful 3D mini-golf game with Nintendo-inspired visuals built with **Three.js** and **Cannon-es** physics.

![Vite](https://img.shields.io/badge/Vite-646CFF?style=flat&logo=vite&logoColor=white)
![Three.js](https://img.shields.io/badge/Three.js-000000?style=flat&logo=three.js&logoColor=white)

## ✨ Features

- 🐰🐸🐥 **3 Playable Characters** — Bunny, Froggy, and Chicky, each with unique 3D models
- 🏌️ **Click & Drag** to aim and control power
- 🌳 **Cute Decorations** — Low-poly trees, flowers, floating clouds, shimmering pond, animated flag
- 🎯 **Real Physics** — Cannon-es handles ball rolling, wall bounces, and hole detection
- ⛳ **Score Messages** — Hole in One, Eagle, Birdie, Par
- 🔄 **Play Again** button after completing the hole
- 📱 Touch support for mobile

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Then open `http://localhost:5173` in your browser.

## 🎮 How to Play

1. Pick your character on the selection screen
2. Click and drag backwards on the screen to aim and set power
3. Release to putt!
4. Get the ball in the hole in as few strokes as possible

## 🛠️ Tech Stack

- **Vite** — Fast build tool
- **Three.js** — 3D rendering
- **Cannon-es** — 3D physics engine
